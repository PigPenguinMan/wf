## 2. 3대 클래스별 2등신 SD 도트 디자인 컨셉

1. **워리어 (Warrior SD)**
   - **머리**: 삐죽한 금발/적갈색 머리카락 + 이마의 갑충 뿔 머리띠 또는 붉은 깃털 투구
   - **무기**: 작은 몸집만 한 거대한 **갑충 파쇄 대검**을 옆에 들고 있으며, 차지 시 몸 주변에 화사한 불꽃/오라 도트 연출
2. **스카우터 (Scouter SD)**
   - **머리**: 산뜻한 포니테일/단발 + 초록색 사냥꾼 두건/망토
   - **무기**: 양손에 쥐어진 하얀 **늑대 송곳니 쌍단검** + 허리춤의 미니 화승총
3. **가디언 (Guardian SD - 반사 탱커)**
   - **머리**: 가디언 테일즈 기사 감성의 **바이저 헬멧(붉은 폼폼/깃털 장식)** 사이로 초롱초롱한 눈과 볼터치가 보이는 디자인
   - **무기**: 캐릭터 키만 한 **가시 등껍질 대방패**와 한손 둔기/검

## 3. 배경 타일셋 & 몬스터 톤앤매너 (`ref/img` 숲 입구 기준)

* **초원 바닥 타일 (`Spr_GrassFloor_64`)**:
  - 어두운 숲 대신 **화사한 라임 그린 투톤 체크보드(`#84E24C` / `#76D442`)** 패턴을 기본 타일로 사용합니다.
  - 타일 곳곳에 **하얀 네잎 꽃송이 군락(`#F8FCF0` 꽃잎 + `#FACD37` 노란 꽃술)**과 황토색 오솔길, 둥근 파스텔톤 바위와 나무 그루터기를 배치합니다.
* **몬스터 SD 디자인**:
  - 몬스터(`초원 뿔토끼`, `광폭한 덕구`, `고대 수호목 엔트`) 역시 험상궂은 실사풍이 아니라, **표정이 살아있고 통통한 SD 픽셀 도트**로 제작하여 캐릭터와 통일감을 이룹니다.
